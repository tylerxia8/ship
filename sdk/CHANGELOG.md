# @ship/sdk Changelog

## 0.0.0

- Initial PlugForge SDK package.
- Typed clients for `documents`, `issues`, `sprints`, `webhooks`, and OAuth app portal operations.
- OAuth Authorization Code + PKCE and Device Authorization Grant helpers.
- In-memory, file, and browser localStorage token stores.
- Async iterator pagination helpers.
- Stripe-style webhook signature verifier.
- Discriminated SDK error union for exhaustive consumer handling.
